# نبرة فيلاد بالعربية

نكتب للناس في السعودية بالعربية من البداية. نبرة فيلاد قريبة وواضحة، وفيها لمسة سعودية خفيفة: «على ذوقك»، «يا هلا»، «وش في بالك؟». الجملة تخدم القارئ؛ ما تحتاج تحافظ على صياغة الشعار الإنجليزي أو استعاراته.

## حسب المكان

- **التصفّح والمحتوى التعريفي:** كلام دافئ وطبيعي. «تفاصيل يومك، على ذوقك» و«وراء كل تصميم، فنان».
- **الأزرار والحقول:** فعل واضح يبيّن الخطوة الجاية. «أضف إلى السلة»، «حفظ المسودة»، «إرسال للمراجعة».
- **الطلبات والدفع والتوصيل:** حالة الطلب ومبلغه والخطوة المطلوبة بدقة. ما نقول إن الطلب مدفوع أو مشحون قبل حدوث ذلك، ولا نضيف مدة توصيل أو وعدًا غير مؤكّد.
- **الحساب والأمان:** تعليمات مباشرة وحدود واضحة، مثل انتهاء رابط التأكيد بعد ساعة واستخدامه مرة واحدة. نحتفظ بالرد العام لطلب تغيير كلمة المرور حتى ما نكشف وجود حساب لشخص آخر.
- **أدوات الفنان والإدارة:** مصطلحات عملية ومفهومة. تفاصيل الملف، المقاس، الدقة، الصلاحيات والمبالغ تحتاج وضوحًا أكثر من العبارات التسويقية.

## أمثلة

| المكان | الصياغة |
| --- | --- |
| الرئيسية | تفاصيل يومك، على ذوقك. |
| دعوة للتصفّح | شوف اللي يعجبك |
| تسجيل الدخول | يا هلا بعودتك. |
| البحث بدون نتيجة | ما لقينا نتيجة لبحثك. |
| متابعة الطلب | وين وصل طلبك؟ |
| رفع التصميم | خلّ تصميمك يصير منتج. |
| نموذج التصميم الشخصي | من فكرتك، وعلى ذوقك. |
| التعريف بالفنانين | وراء كل تصميم، فنان. |

## مصطلحات نعتمدها

| المعنى | المصطلح |
| --- | --- |
| Shopping bag / cart | السلة |
| Phone case | غطاء جوال |
| Tote bag | شنطة قماش |
| Promo code | كود الخصم |
| Product category | قسم المتجر |
| Original artwork file | ملف التصميم الأصلي |
| Product mockup | معاينة المنتج |
| Draft | مسودة |
| Final proof | المعاينة النهائية |
| Artist review | مراجعة التصميم |

«يا هلا» تناسب الترحيب، مو كل رسالة. نستخدم «خلّ» و«تقدر» و«اللي» حيث تخدم الجملة، ونحتفظ بالعربية الواضحة في التفاصيل الحساسة. نتجنب المبالغة في اللهجة، والتعابير المرتبطة بمنطقة واحدة، والإكثار من التعجب أو الإيموجي.

عبارة «التوصيل علينا» قد تُفهم كشحن مجاني؛ نستخدم «نتولى الطباعة والتوصيل» عند شرح دور فيلاد. الشحن المجاني يُذكر فقط عندما تتحقق شروطه الفعلية. ما نضيف ادعاءات عن بلد التصنيع أو المورّد أو الضريبة أو جودة الطباعة النهائية دون معلومات مؤكّدة. المعاينات المبدئية تبقى موصوفة بوضوح.

## التطبيق

نصوص الواجهة في `public/assets/locales/ar.js`، وعناوين الصفحات والمشاركة في `src/locales.js`، ورسائل تأكيد البريد وتغيير كلمة المرور في `src/email-verification.js`. مفاتيح الترجمة والمسارات ومتغيرات مثل `{name}` و`{amount}` ثابتة. نراجع الأجزاء المنفصلة من العنوان كجملة كاملة، ونحافظ على فواصل الأسطر المقصودة.

العناوين والأوصاف التي يكتبها الفنانون أو الإدارة لها حقول عربية مستقلة في لوحة التحكم؛ لا يستبدل تحديث نبرة الواجهة محتواهم. تبقى الأسعار والخيارات وحالات الطلب بيانات فعلية، وليست عبارات تسويقية قابلة لإعادة التأويل.

قبل النشر، نراجع العربية على شاشة جوال وسطح مكتب: طول الأزرار، فواصل العناوين، البحث، السلة، تسجيل الدخول، محرر التصميم ولوحات الفنان والإدارة. أرقام الطلبات وعناوين البريد والمتغيرات والأسعار تحتاج أن تبقى مقروءة مع اتجاه الصفحة من اليمين لليسار. نعزل عبارة البحث لاتينية الاتجاه داخل عنوان عربي باستخدام `bdi`، مع تهريب النص قبل عرضه. في العدّادات العامة نستخدم عبارات مثل «عدد التصاميم: 2» حتى تبقى الصياغة سليمة مع كل عدد.
